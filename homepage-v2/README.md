The page retains the Figma serif display family, EB Garamond, and uses Inter for body copy. Body text is 18px/30px on desktop for browser readability, with fluid rails and text reflow. The principal 1600px rails retain the design's 1440px header/credentials, 1196px content, and 1102px introduction widths. Wider browsers expand the rails proportionally. Smaller viewports use explicit tablet and mobile layouts.

Every photo and icon comes from this Figma frame. Photos are cropped inside their design slots so stock-preview footer bars stay outside the visible area; the source images and their watermarks are retained. Mirroring follows the source design. Existing shared assets have identical bytes to their V1 copies.

Mobile navigation, FAQ expand/collapse, anchor scrolling, email and telephone links work. Both forms are local demonstrations with browser validation and an explicit non-transmitting confirmation. No form backend or deployment is connected. Placeholder wording in the mockup is intentionally retained.
