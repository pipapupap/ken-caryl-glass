# Ken Caryl Glass Design Studies

Open `index.html` for the combined hub: four homepage studies and two residential service-page studies.

## Folder structure

- `assets/`: shared images, icons, and fonts for every page.
- `Homepage Studies/`: existing homepage versions and project notes.
- `Service Pages/`: residential glass versions 1 and 2.

The index files inside the two study folders redirect to the main hub, preserving the old hub addresses.

## GitHub Pages

Upload this folder's contents to the repository root. In Settings → Pages, choose Deploy from a branch, the main branch, and the root folder. No build step is needed. Keep all folder names and relative paths intact.

Forms are visual mockups. Stock placeholders remain watermarked and need appropriate licensing before production publication. Existing asset records are retained with the studies.
